Cada trecho: de onde, para onde e em que dia (de 2 a 5). O destino de um vira a origem do próximo, mas você pode trocar (ex.: voltar por outra cidade).

Conexão com o GitHub

Para cadastrar buscas e disparar coletas, a página precisa de um token seu. Ele fica salvo só neste navegador e é enviado somente para api.github.com.

  1. Abra Fine-grained tokens → New.
  2. Em Repository access, escolha Only select repositories e marque só este repositório.
  3. Em Permissions → Repository: Contents: Read and write e Actions: Read and write.
  4. Gere o token e cole abaixo.
